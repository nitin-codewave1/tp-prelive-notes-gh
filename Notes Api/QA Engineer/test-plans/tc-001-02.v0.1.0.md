# TC-001-02: [edge] POST /notes is called

**Story:** [[US-001-01]]
**Module:** create a new note via the API with a title, markdown body and tags

## Preconditions
the request omits the title field

## Expected Result
the API returns 400 with a validation error and no note is created

## Acceptance Criteria
Given an authenticated team member sends valid title, body and tags, when POST /notes is called, then a note is persisted with a generated id, timestamp, and the submitted fields, returned in the response
Given the request omits the title field, when POST /notes is called, then the API returns 400 with a validation error and no note is created
Given no valid auth session is present, when POST /notes is called, then the API returns 401 and no note is created

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |
|---|---|---|---|---|
| 1 | Authenticate as a team member | navigate | `POST /auth/login` | {"email":"member@test.com","password":"ValidPass123"} |
| 2 | Send POST /notes omitting the title field | navigate | `POST /notes` | {"body":"content","tags":["x"]} |
| 3 | Assert the response status is 400 | assert_text | `response.status` | 400 |
| 4 | Assert no note was created | assert_text | `response.body.error.code` | VALIDATION_ERROR |
