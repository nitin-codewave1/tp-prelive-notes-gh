# TC-001-04: PUT /notes/:id is called with updated title, body or tags

**Story:** [[US-001-02]]
**Module:** edit an existing note's title, markdown body or tags

## Preconditions
a note with a known id exists

## Expected Result
the stored note is updated and the new values are returned

## Acceptance Criteria
Given a note with a known id exists, when PUT /notes/:id is called with updated title, body or tags, then the stored note is updated and the new values are returned
Given the note id does not exist, when PUT /notes/:id is called, then the API returns 404 and no update occurs
Given no valid auth session is present, when PUT /notes/:id is called, then the API returns 401 and no update occurs

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |
|---|---|---|---|---|
| 1 | Authenticate as a team member | navigate | `POST /auth/login` | {"email":"member@test.com","password":"ValidPass123"} |
| 2 | Create a note to update | navigate | `POST /notes` | {"title":"Original","body":"old","tags":[]} |
| 3 | Send PUT /notes/{noteId} with updated title, body and tags | navigate | `PUT /notes/{noteId}` | {"title":"Updated","body":"new","tags":["new"]} |
| 4 | Assert response status is 200 | assert_text | `response.status` | 200 |
| 5 | Assert the returned note reflects the new values | assert_text | `response.body.title` | Updated |
