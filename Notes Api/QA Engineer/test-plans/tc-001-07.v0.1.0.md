# TC-001-07: DELETE /notes/:id is called

**Story:** [[US-001-03]]
**Module:** delete a note permanently via the API

## Preconditions
a note with a known id exists

## Expected Result
the note is removed from storage and a subsequent GET for that id returns 404

## Acceptance Criteria
Given a note with a known id exists, when DELETE /notes/:id is called, then the note is removed from storage and a subsequent GET for that id returns 404
Given a note has already been deleted, when DELETE /notes/:id is called again for the same id, then the API returns 404
Given no valid auth session is present, when DELETE /notes/:id is called, then the API returns 401 and no deletion occurs
