# US-001-01: set the pinned flag when creating or editing a note via the API

## Definition

As a **Team member**, I want to **set the pinned flag when creating or editing a note via the API**, so that **so the note is marked as important and will surface first in list/search results**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-01-01]] — Given a valid create or update request includes pinned: true, when the API processes the request, then the note is stored with pinned=true and the response reflects pinned=true
- [[AC-001-01-02]] — Given the pinned field is sent as a non-boolean value, when the API validates the request body, then a 400 validation error is returned and the note is not saved
- [[AC-001-01-03]] — Given the pinned field is omitted from a create request, when the note is created, then pinned defaults to false
