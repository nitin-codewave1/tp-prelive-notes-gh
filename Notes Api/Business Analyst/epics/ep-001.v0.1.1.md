# EP-001: Pinned Flag & Pinned-First Ordering

Add a boolean 'pinned' field to the note resource and ensure list/search endpoints return pinned notes first (then newest-first) so members can resurface key notes without relying on search/tags.

**Objective:** [[OBJ-001]]

## Stories
- [[US-001-01]] — set the pinned flag when creating or editing a note via the API
- [[US-001-02]] — retrieve the note list with pinned notes shown first
- [[US-001-03]] — search or filter notes while pinned-first ordering is preserved
- [[US-001-04]] — get list and search responses within 300ms even with pinned-first ordering applied
- [[US-001-05]] — toggle the pinned status of an existing note without submitting a full edit
- [[US-001-06]] — have archived notes excluded from pinned-first ordering until restored
