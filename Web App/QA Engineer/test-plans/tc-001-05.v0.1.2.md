# TC-001-05: the team member toggles the pin control to pin it

**Story:** [[US-001-03]]
**Module:** pin or unpin the note from the detail screen

## Preconditions
a note's detail view shows it as unpinned

## Expected Result
the detail view shows the note as pinned and the state persists on reload

## Acceptance Criteria
Given a note's detail view shows it as unpinned, when the team member toggles the pin control to pin it, then the detail view shows the note as pinned and the state persists on reload
Given the user's session has expired, when the team member toggles the pin control on the detail view, then the action is rejected and the user is prompted to log in again

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |
|---|---|---|---|---|
| 1 | Navigate to the note detail view of an unpinned note | navigate | `/notes/1` |  |
| 2 | Confirm the detail view shows the note as unpinned | assert_visible | `[data-testid="US-001-03-note-detail-pin-control"]` |  |

| 4 | Verify the detail view shows the note as pinned | assert_visible | `[data-testid="US-001-03-pinned-badge"]` |  |
| 5 | Reload the page | navigate | `/notes/1` |  |
| 6 | Verify pinned state persists after reload | assert_visible | `[data-testid="US-001-03-pinned-badge"]` |  |
