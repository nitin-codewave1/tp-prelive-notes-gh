# TC-001-07: the team member opens the note list

**Story:** [[US-001-04]]
**Module:** see pinned notes displayed first, ahead of newest-first ordering

## Preconditions
the list contains both pinned and unpinned notes

## Expected Result
all pinned notes appear first, followed by unpinned notes in newest-first order

## Acceptance Criteria
Given the list contains both pinned and unpinned notes, when the team member opens the note list, then all pinned notes appear first, followed by unpinned notes in newest-first order
Given no notes are pinned, when the team member opens the note list, then notes display in standard newest-first order with no pinned section shown

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |

| 1 | Navigate to the notes list containing pinned and unpinned notes | navigate | `/notes` |  |

| 3 | Verify unpinned notes follow in newest-first order | assert_visible | `[data-testid="US-001-04-unpinned-section"]` |  |
