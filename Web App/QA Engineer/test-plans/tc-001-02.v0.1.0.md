# TC-001-02: [error] they click Save with the title field empty

**Story:** [[US-001-01]]
**Module:** create a new note with a title, markdown body and tags

## Preconditions
the team member is on the new note screen

## Expected Result
the form shows an inline validation error and the note is not saved

## Acceptance Criteria
Given the team member is logged in and on the new note screen, when they enter a title, markdown body, at least one tag, and click Save, then the note is created and the team member is returned to the notes list with the new note shown first
Given the team member is on the new note screen, when they click Save with the title field empty, then the form shows an inline validation error and the note is not saved
Given the team member is creating a note, when they click Save without entering any tags, then the note is saved successfully with an empty tag list

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |
|---|---|---|---|---|
| 1 | Log in and go to new note screen | navigate | `/notes/new` |  |
| 2 | Leave title empty, fill body | fill | `[data-testid="note-form-body-textarea"]` | Body text |
| 3 | Click Save | click | `[data-testid="note-form-save-button"]` |  |
| 4 | Verify inline validation error shown | assert_visible | `[data-testid="note-form-title-error"]` |  |
| 5 | Verify still on new note screen | assert_url | `` | /notes/new |
