# TC-001-01: the team member clicks the pin control on that note

**Story:** [[US-001-01]]
**Module:** pin an important note from the list view

## Preconditions
an unpinned note is visible in the note list

## Expected Result
the note is marked pinned and moves to the top of the list above all unpinned notes

## Acceptance Criteria
Given an unpinned note is visible in the note list, when the team member clicks the pin control on that note, then the note is marked pinned and moves to the top of the list above all unpinned notes
Given the pin request fails (e.g. network/API error), when the team member clicks the pin control, then the note remains unpinned in the list and an error message is shown

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |
|---|---|---|---|---|
| 1 | Navigate to the notes list | navigate | `/notes` |  |
| 2 | Confirm an unpinned note's pin control is visible | assert_visible | `[data-testid="US-001-01-pin-control"]` |  |
| 3 | Click the pin control on that note | click | `[data-testid="US-001-01-pin-control"]` |  |
| 4 | Verify the note now shows a pinned badge | assert_visible | `[data-testid="US-001-01-pinned-badge"]` |  |
| 5 | Verify the note is first within the pinned section, above unpinned notes | assert_visible | `[data-testid="US-001-01-pinned-section"] li:first-child [data-testid="US-001-01-pinned-badge"]` |  |
