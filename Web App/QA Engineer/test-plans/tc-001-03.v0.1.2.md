# TC-001-03: the team member clicks the unpin control on that note

**Story:** [[US-001-02]]
**Module:** unpin a note from the list view

## Preconditions
a pinned note is visible at the top of the list

## Expected Result
the note is marked unpinned and moves back into newest-first order among unpinned notes

## Acceptance Criteria
Given a pinned note is visible at the top of the list, when the team member clicks the unpin control on that note, then the note is marked unpinned and moves back into newest-first order among unpinned notes
Given multiple notes are pinned, when one pinned note is unpinned, then the remaining pinned notes stay pinned and retain their relative order at the top

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |
|---|---|---|---|---|
| 1 | Navigate to the notes list | navigate | `/notes` |  |
| 2 | Confirm a pinned note is visible at the top | assert_visible | `[data-testid="US-001-02-pinned-section"] li:first-child` |  |
| 3 | Click the unpin control on that note | click | `[data-testid="US-001-02-unpin-control"]` |  |
| 4 | Verify the note is marked unpinned and placed newest-first among unpinned notes | assert_visible | `[data-testid="US-001-02-notes-list"] [data-testid="US-001-02-pin-control"]` |  |
