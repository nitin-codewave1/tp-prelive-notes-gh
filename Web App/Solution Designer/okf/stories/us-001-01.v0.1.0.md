# US-001-01

As a team member viewing the note list, I want to pin an important note from the list view, so that mark high-priority notes so they surface first for fast retrieval, driving adoption of pinning. - Given an unpinned note is visible in the note list, when the team member clicks the pin control on that note, then the note is marked pinned and moves to the top of the list above all unpinned notes - Given the pin request fails (e.g. network/API error), when the team member clicks the pin control, then the note remains unpinned in the list and an error message is shown - Test case: the team member clicks the pin control on that note - Test case: [error] the team member clicks the pin control
