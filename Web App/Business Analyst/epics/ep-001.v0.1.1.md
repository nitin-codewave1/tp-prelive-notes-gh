# EP-001: Pin/Unpin Note Action

Let a team member mark a note as pinned/unpinned from the note list and detail views, so important notes are flagged for fast retrieval.

**Objective:** [[OBJ-001]]

## Stories
- [[US-001-01]] — pin an important note from the list view
- [[US-001-02]] — unpin a note from the list view
- [[US-001-03]] — pin or unpin the note from the detail screen
- [[US-001-04]] — see pinned notes displayed first, ahead of newest-first ordering
- [[US-001-05]] — see pin status reflected correctly while searching by text or filtering by tag
- [[US-001-06]] — see that pin controls are unavailable on archived notes
