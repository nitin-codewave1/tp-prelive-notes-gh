# EP-001: Note Creation, Editing & Deletion UI

Forms/views for creating, editing and deleting notes (title, markdown body, tags); core workflow that drives note volume and tagging adoption.

**Objective:** [[OBJ-001]]

## Stories
- [[US-001-01]] — create a new note with a title, markdown body and tags
- [[US-001-02]] — edit the title, markdown body or tags of an existing note
- [[US-001-03]] — delete a note they no longer need
- [[US-001-04]] — add or remove tags while creating or editing a note
- [[US-001-05]] — preview the rendered markdown while writing a note's body
- [[US-001-06]] — discard unsaved changes when leaving the note form
