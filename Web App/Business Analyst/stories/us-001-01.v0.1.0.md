# US-001-01: create a new note with a title, markdown body and tags

## Definition

As a **Team member**, I want to **create a new note with a title, markdown body and tags**, so that **quickly capture shared knowledge so note volume grows toward the 30-day creation KPI**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-01-01]] — Given the team member is logged in and on the new note screen, when they enter a title, markdown body, at least one tag, and click Save, then the note is created and the team member is returned to the notes list with the new note shown first
- [[AC-001-01-02]] — Given the team member is on the new note screen, when they click Save with the title field empty, then the form shows an inline validation error and the note is not saved
- [[AC-001-01-03]] — Given the team member is creating a note, when they click Save without entering any tags, then the note is saved successfully with an empty tag list
